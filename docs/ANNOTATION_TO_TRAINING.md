# 从标注到训练：端到端流程

本文给出一条从零到可发布模型的最小闭环。适合第一次使用 Label Once 的读者；每一步都链接到更细的文档。

---

## 0. 准备

```powershell
./scripts/install.ps1          # 环境、依赖、.NET SDK、模型权重
./desktop/scripts/start.ps1    # 编译并启动 WPF
```

确保 `models/` 至少有一个 YOLO 权重（如 `yolo11n.pt`），`sam/` 至少有一个 SAM/SAM2 权重（如 `sam2_t.pt`，用于视频跟踪）。

---

## 1. 新建项目与类别

1. 首页 → “新建/打开项目”，选择一个空目录；
2. 打开“管理类别”，按业务顺序建立类别；
3. 类别顺序就是类别 ID，后续**只追加，不移动**；改名/重排必须走显式映射并会备份标签。

详细格式见 [项目目录与数据格式](./03-project-layout-and-formats.md)。

---

## 2. 导入素材

### 图片

- 标注页 → “项目 → 导入”，选择文件或目录；
- 若同目录存在 YOLO 标签，会按类名自动对齐；
- 导入后样本进入新批次，状态 `pending`。

### 视频

- 视频页 → 打开视频 → 设置抽帧间隔（默认 0.5 秒或 10 帧）；
- 抽帧完成后自动导入为新批次；
- 只导入 `state=complete` 的抽帧结果。

详见 [视频抽帧与 SAM2 跟踪](./05-video-workflow.md)。

---

## 3. 标注

### 人工

- `W` 绘框，拖动控制点调整；
- `P` 绘制多边形，双击完成；
- `Ctrl+Z/Y` 撤销重做，`Delete` 删除；
- `A/D` 连续切图，`R` 适配视图。

### SAM 辅助

- `Q` 前景点，`E` 背景点；
- 可加框提示和 ROI；
- “新目标”开始下一组，“清除本次分割”恢复；
- 结果只是候选，需接受并保存。

### 保存与确认

- 保存成功后才切图；
- `F` = 保存 + 确认 + 下一张；
- 空图片也要保存空 `.txt` 并确认，作为负样本；
- 修改几何会让已确认状态退回 pending。

详见 [图像标注与复核](./04-annotation-workflow.md)。

---

## 4. 创建数据集版本

训练页 → “数据集”：

1. 设置 train/val/test 比例（默认 0.7/0.2/0.1）；
2. 设置随机种子（默认 42）；
3. 创建版本；
4. 检查版本统计：样本数、类别分布、各 split 数量、是否有空集合/跨集合分组。

只有 `confirmed` 和 `legacy` 样本会入选；`pending/rejected` 被排除。视频帧/同批导入会整组进入同一 split。

激活版本后，训练默认使用它。详见 [数据集版本与整合](./06-dataset-workflow.md)。

---

## 5. 配置训练

训练页参数：

| 字段 | 建议 |
| --- | --- |
| epochs | 先用 50–100 试跑 |
| batch | 受显存限制；默认 16 |
| lr0 | 默认 0.001（AdamW） |
| imgsz | 640；必须是 32 的倍数 |
| device | `0` 表示第一块 GPU，`cpu` 表示 CPU |

高级设置中：

- 优化器固定 `AdamW`，不要改回 `auto`；
- `nbs` 影响梯度累积；
- 数据增强按任务调整（小数据集慎用强 mosaic）。

预设会按 [训练文档](./07-training-evaluation-export.md) 的优先级合并。

---

## 6. 训练

点击“训练”：

- 后端创建 `runs/train_.../`；
- 进度与 epoch 指标实时推送；
- 训练完成后 `best.pt` 复制到 `Model/<run>.pt`；
- 参数/指标/数据集版本写入 `Model/experiments.jsonl`。

中断后可在训练页“续训”，只接受当前项目 `runs/` 下的 `last.pt`。

---

## 7. 评估

模型页 → “评估”：

- 在数据集的 `test` split 上运行 `YOLO.val`；
- 输出整体指标与逐类指标；
- 结果目录在 `runs/evaluate_.../evaluation`。

如果 test split 为空，先调整比例或补充样本。

---

## 8. 发布门禁

发布前必须跑门禁：

1. 选择待发布模型；
2. 选择冻结基准集 `dataset.yaml`；
3. 可选：基线模型、量化模型；
4. 设置阈值。

门禁检查：

- 类别顺序；
- 基准集标签格式；
- 基准集与训练集泄漏；
- 整体 mAP50 下限；
- 逐类 AP50 跌幅；
- 量化掉点。

通过后报告写入 `Model/release_gate.json`。详见 [发布门禁](./08-release-gate.md)。

---

## 9. 导出与交付

模型页 → “导出”：

- ONNX：跨平台首选；
- OpenVINO：Intel 部署；
- TensorRT：NVIDIA 部署，engine 与机器绑定；
- TorchScript：PyTorch 运行时。

INT8 导出必须提供校准数据集。导出后建议再跑一次门禁（尤其量化模型）。

交付时保留：

- 模型权重（`.pt` + 导出格式）；
- `release_gate.json`；
- 数据集版本号；
- 训练参数/实验记录；
- 必要的类别表与推理说明。

---

## 10. 常见返工点

| 阶段 | 返工原因 | 预防 |
| --- | --- | --- |
| 标注 | 空图片未确认 | 每张都按 `F`，包括负样本 |
| 数据集 | 验证集泄漏 | 依赖批次/视频分组，检查 `leaked_groups` |
| 训练 | 学习率无效 | 保持 AdamW，不用 auto |
| 评估 | 类别顺序错 | 只追加类别，合并时看 alias |
| 门禁 | 基准集被训练 | 用黑名单固定 golden 到 val |
| 导出 | engine 换机失效 | 在目标机器重新导出 |
| 交付 | 缺报告/版本 | 把门禁报告与实验记录一起归档 |
